# Getting help

## Start here

- [Getting started](docs/GETTING_STARTED.md) covers installing, playing, updating,
  and removing everything, and ends with "If something goes wrong".
- [The README](README.md) lists what works and what does not, yet.
- [Architecture](docs/ARCHITECTURE.md) explains how the host works, for those who
  want to dig in.

## Where to ask

| You have | Go to |
| --- | --- |
| A question about installing, playing, or building | [Discussions, Q&A](https://github.com/jhenrique09/cs2metal/discussions/categories/q-a) |
| An idea | [Discussions, Ideas](https://github.com/jhenrique09/cs2metal/discussions/categories/ideas), or a feature request if it is concrete |
| Something that does not work as documented | [A bug report](https://github.com/jhenrique09/cs2metal/issues/new/choose) |
| A game update that broke it | [The game update form](https://github.com/jhenrique09/cs2metal/issues/new/choose) |
| A security problem | [A private advisory](https://github.com/jhenrique09/cs2metal/security/advisories/new), never an issue |

Search first: the answer may already be there.

## What the project cannot help with

- **Valve Anti-Cheat, bans, and accounts.** Valve does not support this host, and
  the project does not study anti-cheat. Read
  [the policy](docs/ANTI_CHEAT_AND_INTEGRITY_POLICY.md) before you play online.
- **Intel Macs, and the Windows build of the game.** The host runs the Linux build
  on Apple silicon only.
- **Copies of the game.** The game comes from Steam, through `install.sh`. Nobody
  here shares game files.

cs2metal is a volunteer project, not affiliated with or endorsed by Valve or Apple.
Answers come when someone has the time.
